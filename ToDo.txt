ТЕХНІЧНЕ ЗАВДАННЯ: СИСТЕМА ПРАВ ДОСТУПУ ТА УПРАВЛІННЯ МЕНЮ

Версія: 1.0
Дата: 2026-01-27


1. ЗАГАЛЬНА МЕТА

Створити гнучку систему розмежування доступу для складського обліку на основі груп Nextcloud (адміністратори), індивідуальних прав користувачів (ролі manager, viewer, fuel) та обмежень по об'єктах (склади, матеріали, типи ресурсів). Пункти меню зберігаються в базі даних замість хардкоду в layout.php.


2. ІСНУЮЧА СИСТЕМА

PHP 7.4/8.x без фреймворку, MySQL/MariaDB, MVC архітектура, авторизація через Nextcloud (NC_USER, NC_GROUPS в сесії). Вже реалізовано склади, матеріали, рухи, ресурси, норми списання.

3.1. Таблиця menu_items (пункти меню)

CREATE TABLE menu_items (
    id INT PRIMARY KEY AUTO_INCREMENT,
    controller VARCHAR(100) NOT NULL UNIQUE,
    label VARCHAR(255) NOT NULL,
    parent_id INT DEFAULT NULL,
    sort_order INT DEFAULT 0,
    icon_svg VARCHAR(500) DEFAULT NULL,
    url VARCHAR(255) DEFAULT NULL,
    is_enabled BOOLEAN DEFAULT TRUE,
    requires_date_range BOOLEAN DEFAULT FALSE,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    FOREIGN KEY (parent_id) REFERENCES menu_items(id) ON DELETE SET NULL,
    INDEX idx_parent (parent_id),
    INDEX idx_order (sort_order),
    INDEX idx_controller (controller)
);

3.4. Таблиця user_menu_permissions (права на пункти меню)

CREATE TABLE user_menu_permissions (
    id INT PRIMARY KEY AUTO_INCREMENT,
    nc_user VARCHAR(255) NOT NULL,

    access_level ENUM('none', 'view', 'edit') NOT NULL DEFAULT 'none',

    FOREIGN KEY (menu_item_id) REFERENCES menu_items(id) ON DELETE CASCADE,
    INDEX idx_user (nc_user),
    INDEX idx_level (access_level)
);

4. ЗНАЧЕННЯ РОЛЕЙ ТА РІВНІВ ДОСТУПУ

Роль manager: редагування рухів, ресурсів, довідників, перегляд звітів.
Роль viewer: тільки перегляд, не може створювати, редагувати, видаляти.
Роль fuel: тільки інтерфейс "Заправка" (SimpleController).

Рівень none: пункт не видно в меню, прямий доступ заборонено (403).
Рівень view: пункт видно в меню, дозволені GET-запити (index, getone, history, export).
Рівень edit: все з view + POST-запити (save, delete, import, add, editlog).

Типові права для ролей:
- manager: всі пункти edit, крім admin (none)
- viewer: movements/view, resources/view, reports/view, інші none
- fuel: simple/edit, всі інші none

- canExport(string $ncUser): bool
- canImport(string $ncUser): bool
- logActivity(string $action, string $controller, ?int $itemId, ?array $details): void

Логіка canAccess():
1. Якщо nc_user порожній -> false
2. Якщо є група 'admin' в nc_groups -> true
3. Отримати menu_item за controller
4. Якщо menu_item не існує -> false
5. Отримати access_level з user_menu_permissions
6. Якщо access_level = 'none' -> false
7. Якщо access_level = 'view' -> дозволені тільки VIEW_METHODS
8. Якщо access_level = 'edit' -> true
9. Інакше -> false

7. КОНТРОЛЕРИ

7.1. Нові методи AdminController.php

users() - GET /admin/users - список користувачів
userEdit($id) - GET /admin/users/edit/{id} - форма редагування користувача
userSave() - POST /admin/users/save - збереження користувача
userDelete($id) - POST /admin/users/delete/{id} - видалення користувача
menu() - GET /admin/menu - управління пунктами меню
menuSave() - POST /admin/menu/save - збереження меню
menuReorder() - POST /admin/menu/reorder - drag&drop сортування
permissions($userId) - GET /admin/permissions/{id} - права на пункти меню
permissionsSave() - POST /admin/permissions/save - збереження прав

Всі методи перевіряють checkAdmin() на початку.

10. ОНОВЛЕННЯ LAYOUT.PHP

Замість хардкодного меню:

$menuModel = new MenuModel($db);
$menuItems = $menuModel->getUserMenu(NC_USER);

foreach ($menuItems as $group):
    if (empty($group['items'])) continue;
    echo '<div class="nav-group">';
    echo '<div class="nav-group-label">' . htmlspecialchars($group['label']) . '</div>';
    foreach ($group['items'] as $item):
        $url = $item['url'] ?? BASE_PATH . '/' . $item['controller'];
        if ($item['requires_date_range']) {
            $url .= '?date_from=' . urlencode($globalDateFrom) . '&date_to=' . urlencode($globalDateTo);
        }
        $active = ($activePage === $item['controller']) ? 'active' : '';
        echo '<a href="' . $url . '" class="nav-item ' . $active . '">';
        if (!empty($item['icon_svg'])) echo $item['icon_svg'];
        echo '<span>' . htmlspecialchars($item['label']) . '</span>';
        echo '</a>';
    endforeach;
    echo '</div>';
endforeach;


11. СИНХРОНІЗАЦІЯ КОНТРОЛЕРІВ

Метод MenuModel::syncFromFiles():

1. Сканує директорію controllers/
2. Знаходить всі файли *Controller.php
3. Виключає допоміжні: Export, Import, Helper, Report, Rates, SimpleDataHelper, Model, Controller, Database
4. Для кожного нового контролера визначає групу за замовчуванням:
   - Довідники: warehouses, materials, resourcetypes, resourcerates
   - Документи: movements, resources, dashboard
   - Звіти: reports
   - Система: simple, settings, admin
5. Додає новий пункт в menu_items з label = оригінальна назва контролера
6. Повертає масив доданих контролерів
